# R&D 성과구조 진단 도구 (rnd-profiler)

공공 R&D 집계 CSV를 넣으면 **합계 검산 → 집계표 → 성과 밀도·유형 → 투입 집중도 → 점검 후보**를 한 화면에 보여 주고, 결과를 파일(`out/`)로 저장하는 도구입니다. 서버·AI·API 키가 없고, 모든 계산은 브라우저(또는 Node 테스트) 안에서 규칙대로만 이뤄집니다.

한양대 과학기술정책학과 「과학기술정책 연구도구」 과제 ⑤ 연구·R&D 데이터 대시보드 유형입니다. 흐름은 `내 자료(붙여넣기·CSV) → 기준 파일(프로필) → 표·그래프 → 내보내기(CSV·마크다운)`입니다.

## 쓰는 법

1. `index.html`을 브라우저로 엽니다(더블클릭으로 충분합니다). GitHub Pages로 올려도 같습니다. 파일 하나만 필요하면 `dist/rnd-profiler.html`을 쓰세요.
2. **KEIT 예시 불러오기**를 누르거나, CSV를 고르거나, 표를 붙여 넣고 **분석하기**를 누릅니다.
3. 컬럼이 맞는 기준(프로필)이 자동 선택됩니다. 맞는 프로필이 없으면 **컬럼 직접 지정**에서 역할을 고르면 새 프로필이 만들어지고 JSON으로 내려받을 수 있습니다.
4. 맨 아래 **저장**에서 `out.zip`(결과 7개 파일), 폴더 저장(Chrome·Edge), 요약 복사를 고릅니다. 정적 페이지는 컴퓨터 폴더에 직접 쓸 수 없어 이렇게 제공합니다.
5. 같은 계산을 명령줄로도 돌립니다: `node tests/check_expected.js` (예시 입력 → `out/` 저장 → 기대 결과와 비교).

## 구성

```
index.html · css/style.css
js/core.js     계산 코어(파싱·지표·검산·내보내기). 브라우저와 Node가 같이 씀
js/charts.js   외부 라이브러리 없는 SVG 차트
js/app.js      화면 동작 · js/data.js 내장 예시(tools/build.js가 생성)
profiles/      기준 파일: keit_performance.json, sample_other_org.json
examples/      예시 입력 CSV 2개 + expected/(기대 결과)
out/           예시를 돌린 결과(프로필별 폴더)
tests/check_expected.js
tools/build.js 내장 데이터·단일 HTML 생성
```

## 기준 파일(프로필)

컬럼 이름과 판정 기준은 코드에 박혀 있지 않고 `profiles/*.json`에 있습니다. 다른 기관 자료는 프로필만 추가하면 됩니다(`sample_other_org.json`은 컬럼명·단위가 다른 가상 예시).

| 항목 | 뜻 |
|---|---|
| `columns.input` | 투입(출연금·연구비). 필수 |
| `columns.count` | 과제 수(과제당 평균 계산) |
| `columns.paper` / `patent` | 논문·특허 컬럼(여러 개면 합산) |
| `columns.group` | 집계표 기준 그룹 |
| `columns.label` | 행 이름으로 쓸 컬럼 |
| `columns.year` | 연도(값이 2개 이상일 때만 추이 표시) |
| `units.densityPer` | 밀도 기준(예: 출연금 10억원당) |
| `thresholds` | 유형·점검 후보·집중도 기준값 (화면에서도 조정 가능) |

필요한 컬럼이 없으면 그 지표만 자동으로 꺼지고, 어떤 기능이 꺼졌는지 화면과 `run_meta.json`에 적힙니다.

## 지표 정의

- **과제당 평균 투입** = 투입 ÷ 과제 수
- **논문 밀도 / 특허 밀도 / 복합 밀도** = (논문 / 특허 / 논문+특허) ÷ 투입 × 기준(예: 10억원)
- **성과 유형**: 논문 비중 ≥ 65% 논문형, ≤ 35% 특허형, 그 사이 균형형, 성과 0이면 성과 없음
- **점검 후보**: 투입 상위 25% 이면서 복합 밀도 하위 40%. 유형과 독립이며 부실 판정이 아니라 추가 확인 대상
- **집중도**: 투입 상위 10% 행의 비중, 누적 곡선, 지니계수
- **검산**: 원본 합계 = 분석 대상 + 제외, 집계표 합계 = 원본 합계. 이중 집계 의심(같은 연도·그룹·항목 중복)과 숫자로 읽히지 않은 칸도 표시
- 투입이 0이거나 비어 있는 행은 밀도를 계산할 수 없어 지표에서 제외하고 별도 표로 둡니다. 합계에는 남깁니다.
- 분위수는 선형보간(exclusive) 방식입니다.

## 예시 자료와 출처

- `examples/input_keit_2024.csv`: 한국산업기술기획평가원(KEIT) 「산업기술 연구개발 성과조사정보」 2024.12.31 기준, 268행. 공공데이터포털 <https://www.data.go.kr/data/15105259/fileData.do>, 이용허락범위 제한 없음. 원본 그대로이며 개인정보가 없는 집계 자료입니다.
- `examples/input_other_org.csv`: 범용성을 보이기 위해 만든 **가상** 자료입니다.

예시 KEIT 자료의 결과 요약: 분석 대상 107행(제외 161행 중 성과가 있는 74행은 별도 표), 출연금 15,938억원, 유형 59/21/12/15, 투입 상위 10%(11행)의 투입 비중 68.6%, 점검 후보 6건. 파이썬으로 따로 계산한 값과 `tests/check_expected.js`가 대조합니다.

## 한계

- 탐색적 선별 도구이며 사업 평가·순위가 아닙니다.
- 성과는 시차를 두고 나타나므로 같은 해 투입과 성과를 바로 대응시키면 왜곡됩니다.
- 사업 목적(원천·사업화·인프라)이 달라 논문·특허 밀도를 사업 간 우열로 읽을 수 없습니다.
- 집계 자료이므로 개별 과제를 추정할 수 없고, 입력 자료의 범위(예: KEIT 관리 산업기술 R&D)만 대표합니다.
- 보조 컬럼(`aux`)은 합산하지 않고 그대로 둡니다(퍼센트·연수 합계는 의미가 없음).
- API 키·개인정보는 코드와 저장소에 없습니다.

## 가져가서 쓰기

설치할 것이 없습니다. Node.js는 `tests/`와 `tools/`를 돌릴 때만 필요하고, 화면은 브라우저만 있으면 됩니다.

| 하고 싶은 일 | 방법 |
|---|---|
| 그냥 써 보기 | `dist/rnd-profiler.html` 한 파일만 내려받아 브라우저로 엽니다 |
| 저장소 통째로 받기 | `git clone` 또는 GitHub의 Code → Download ZIP |
| 내 기관 자료에 맞추기 | `profiles/`에 JSON을 하나 추가합니다(컬럼 역할은 위 표). 화면의 **컬럼 직접 지정**으로 만든 JSON을 넣어도 됩니다 |
| 고친 뒤 확인하기 | `node tools/build.js`(내장 데이터·단일 HTML 재생성) → `node tests/check_expected.js` |

`js/data.js`와 `dist/rnd-profiler.html`은 `tools/build.js`가 만드는 파일이므로 직접 고치지 않습니다.
